# Plantation Tools (Community Edition) for QGIS

![QGIS Plugin](https://img.shields.io/badge/QGIS-3.16+-brightgreen.svg)
![License](https://img.shields.io/badge/License-GPL--3.0-blue.svg)
![Version](https://img.shields.io/badge/Version-2.1.2-orange.svg)

**Plantation Tools** is a comprehensive spatial analysis processing toolbox for QGIS, designed for oil palm plantation management, road network analysis, drainage planning, hydrology, and infrastructure mapping.

This repository contains the **Community Edition (Free Version)** of Plantation Tools published on the official QGIS Plugin Repository.

---

## 🌟 Key Features

### Community Edition (Free)
* **Block & Grid Mapping:** Generate plantation block grids and centroid routing points.
* **Basic Spatial Utilities:** Intercropping distance tools, planting distance estimation, and GeoJSON export.
* **QGIS Processing Framework Integration:** Seamless integration into QGIS Processing Toolbox.

### PRO Edition Features (Unlock Full Capabilities)
To access advanced AI models, automated road optimization, hydrology, and drone mission planning, upgrade to **Plantation Tools PRO**:
* 🤖 **AI-Based Palm Tree Detection:** Detect palm trees automatically from high-resolution RGB orthomosaics.
* 🛣️ **Optimal Road Network & Cut/Fill Routing:** Calculate earthwork volumes and design optimal road alignment.
* 🌊 **Flood Prediction & Hydrology:** Watershed delineation, sink detection, and drainage network planning.
* 🚁 **Drone Mission Planner:** Export flight plans directly to DJI WPML format for drone surveying.
* 🧪 **Chlorosis Detection & Soil Moisture:** Vegetation index analysis (NDVI) and nutrient management.

👉 **Learn more and get PRO Version:** [https://plantationtools.web.id](https://plantationtools.web.id)

## 💻 Installation

### Method 1: QGIS Official Plugin Manager (Recommended)
1. Open QGIS (v3.16 or higher).
2. Go to **Plugins** > **Manage and Install Plugins...**
3. Search for **Plantation Tools**.
4. Click **Install Plugin**.

### Method 2: Manual Installation from ZIP
1. Download `PlantationTools_QGIS_v2.1.2_FREE.zip` from the [Releases](https://github.com/ahzastudio/plantation-tools-free/releases) section.
2. In QGIS, go to **Plugins** > **Manage and Install Plugins...** > **Install from ZIP**.
3. Select the downloaded ZIP file and click **Install Plugin**.
